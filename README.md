# NetOps AI 发行版

本仓库只用于分发 NetOps AI 客户端的安装包，**不包含源代码**。

- 最新版本：**v0.1.0（内测）**
- 下载入口：本仓库的 [Releases](../../releases) 页面
- 安装包命名：`NetOpsOne-<版本>-<系统>-<架构>-setup.exe`

## 系统要求

| 项 | 要求 |
|---|---|
| 操作系统 | Windows 10 / Windows 11 |
| 架构 | x64（64 位） |
| 内存 | 建议 8 GB 及以上 |
| 磁盘 | 安装后占用约 1 GB |
| 权限 | 当前用户安装，**不需要管理员权限** |

暂不支持 32 位系统、Windows 7/8、macOS、Linux。

## 安装

1. 进入 Releases，下载最新版本的 `NetOpsOne-*-windows-x64-setup.exe`
2. 双击运行
3. 若出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」（原因见下）
4. 选择安装目录，一路「下一步」

安装完成后，桌面和开始菜单会出现「NetOps AI」快捷方式。

## 首次启动

首次启动会要求**设置保险库密码**。

这个密码用于加密本机保存的设备登录凭证，只存在于本机：

- 密码本身不落盘，无法被读出
- **忘记密码无法找回**，只能重置保险库并重新录入所有设备凭证
- 之后每次启动都需要输入该密码解锁

请使用一个有备份手段的密码。

## 许可与试用

| 阶段 | 时长 | 可用范围 |
|---|---|---|
| 试用 | 30 天 | 全功能 |
| 宽限期 | 15 天 | 全功能 |
| 只读 | 长期 | 可登录、查看、导出；不能修改数据 |

许可是**按机器绑定**的（四项机器指纹命中三项）。换机器、重装系统后需要重新签发。

申请或续期：打开客户端「设置 → 许可」，复制页面上的机器码，连同客户名称一起发给我们。

## 关于安全提示

当前版本**未做代码签名**，因此：

- 安装时 SmartScreen 会提示「未知发布者」
- 部分杀毒软件（尤其 360、火绒）可能把后端进程 `netops-backend.exe` 误报并隔离

若出现客户端一直停在启动画面、或提示「后端启动超时」，通常是后端子进程被杀软隔离了。请检查杀毒软件的隔离区并恢复，同时把拦截记录反馈给我们，便于提交误报申诉。

签名证书到位后此提示会消失。

## 校验安装包

每个版本发布时都会提供 SHA256，Release 页面和包内同名资产中均可找到。

```powershell
Get-FileHash .\NetOpsOne-0.1.0-windows-x64-setup.exe -Algorithm SHA256
```

若哈希与公布值不一致，请勿安装并联系我们。

也可以在 Release 页面查看 GitHub 自动计算的 digest，两者应当一致。

## 反馈问题

提交 Issue 时请附上：

- 版本号（设置 → 关于）
- 问题现象与复现步骤
- `%APPDATA%\NetOpsOne\logs` 下的日志
- 涉及后端时，另附 `安装目录\resources\backend\logs`

请勿在 Issue 中粘贴设备密码、API Token 或许可内容。

## 卸载与数据

卸载会移除程序文件，**不删除** `%APPDATA%\NetOpsOne` 下的数据（设备、模板、告警历史）。

需要彻底清理时，卸载后手动删除该目录。
